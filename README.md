Проект первого модуля JavaRush University для группы 69 Warrant.
Полное задание лежит на платформе: [Проект модуля 1](https://javarush.com/quests/lectures/jru.module1.lecture51).

Программа шифрует текстовый файл сдвигом по алфавиту, расшифровывает его по известному ключу и подбирает ключ перебором, если ключа нет.


## Режимы работы программы при запуске

1. Зашифровка файла с ключом.
2. Расшифровка файла с ключом.
3. Взлом зашифрованного текста путем перебора ключей (ищет ключ по самому большому количеству пробелов в тексте).
